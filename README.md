# Сервис — учёт ремонта оборудования

Настольное приложение для мастерской: что поступило в ремонт, от кого, откуда, в каком
состоянии и что с ним делали. Работает офлайн, данные хранятся локально.

## Возможности

- Список заявок с поиском, фильтрами по статусу и сортировкой; колонки подстраиваются под ширину окна
- Карточка заявки: смена статуса в один клик, автосохраняемые примечания, лента истории статусов
- Вложения разложены по разделам: входной акт (скан PDF со своим окном просмотра),
  фото и видео со встроенным плеером, документы. У каждого файла прямая ссылка, сохранение и копирование ссылки
- Фото с iPhone в HEIC получают JPEG-копию для просмотра, оригинал сохраняется
- Штамп с датой, временем и названием оборудования поверх фото и видео — состав и угол настраиваются
- Экспорт выбранных или всех отфильтрованных заявок в Excel (три листа) и в постраничный PDF-отчёт A4
- Оформление: тёмная и светлая темы, восемь цветовых гамм или свой HEX, четыре шрифта,
  размер текста, плотность списка, скругление углов
- Компактный виджет поверх других окон со счётчиками и активными заявками

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Главное окно — http://localhost:5180, виджет — http://localhost:5180/widget.html

## Настольное приложение

Оболочка — Tauri 2: главное окно, компактный виджет поверх других окон, значок в трее,
данные в SQLite, файлы в папке приложения.

```bash
npm run tauri dev     # запуск с горячей перезагрузкой
npm run tauri build   # установщик для текущей системы
```

Установщик собирается **на той системе, для которой он предназначен**: `.msi` и `.exe` — на
Windows, `.dmg` — на macOS, `.deb` и `.AppImage` — на Linux. Кросс-сборка Tauri между
системами не поддерживается.

### Готовый установщик без установки инструментов

Проще всего не собирать ничего локально:

1. Вкладка **Actions** в репозитории → workflow **«Сборка приложения»** → **Run workflow**.
2. Через несколько минут внизу страницы запуска появятся артефакты:
   `services-windows` (`.msi` и `.exe`), `services-macos` (`.dmg`), `services-linux`.
3. Скачать нужный архив и установить.

Тег вида `v0.1.0` дополнительно собирает черновик релиза с теми же файлами.

### Первый запуск: приложение не подписано

Сборки не имеют цифровой подписи, поэтому система при первом запуске предупредит.

- **Windows**: в окне SmartScreen нажать «Подробнее» → «Выполнить в любом случае».
- **macOS**: правый клик по приложению → «Открыть» → ещё раз «Открыть».
  Если система всё равно не пускает: `xattr -dr com.apple.quarantine /Applications/Services.app`

Это обычная ситуация для собственных сборок. Подпись потребует Apple Developer Program
и сертификата для Windows — они подключаются в CI через секреты репозитория.

### Сборка на Windows 11 вручную

```powershell
winget install OpenJS.NodeJS.LTS
winget install Rustlang.Rustup
winget install Microsoft.VisualStudio.2022.BuildTools
```

В установщике Build Tools отметить «Разработка классических приложений на C++».
Дальше:

```powershell
git clone https://github.com/atabaevkirill-dev/services.git
cd services
npm install
npm run tauri build
```

Установщик появится в `src-tauri/target/release/bundle/`.

Альтернатива — собирать в GitHub Actions и просто скачивать готовый установщик из артефактов,
не устанавливая Rust и Build Tools на рабочую машину.

## Хранение данных

В настольной сборке заявки лежат в SQLite (`services.db`), файлы — в подпапке `files`
каталога данных приложения. В браузерной версии метаданные хранятся в `localStorage`,
а содержимое файлов — в IndexedDB.
Раздел «Настройки → Данные» позволяет очистить базу целиком и загрузить демонстрационный набор.
